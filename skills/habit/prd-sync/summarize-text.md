# PRD Sync · 文本摘要方法

## 用途

把长文档（用户需求文档 / 会议记录 / 调研笔记）压成 PRD 章节可用的素材。

## 通用流程

```
1. 通读全文（不抄）
2. 提炼关键决策 / 行动项
3. 按 7 类信息归类（见下）
4. 浓缩为 PRD 输入
```

## 7 类信息归类

| 类别 | 在 PRD 哪一节 |
|------|--------------|
| **业务背景** | Overview（一句话定位） |
| **用户角色** | User Story 的 "As a" |
| **核心动作** | User Story 的 "I want to" + Execution Steps |
| **价值/目标** | User Story 的 "So that" |
| **输入条件** | Inputs |
| **输出预期** | Outputs |
| **验收标准** | Success Criteria |

## 实例：会议记录 → PRD

输入（原始会议记录，约 1500 字）：

```
2026-05-20 周会 - 主题：批量导出功能
参会：PM、张老师（教研组长）、刘老师（教师）

张老师：现在每月都要把全班所有人的课件打包发给上级，
       要点开每个学生的课件，下载，再放进 zip。一次要花 1 小时。
PM：所以你希望系统帮你打包？
张老师：对，最好能按月份选，再选班级，一键打包发邮件。
PM：导出格式呢？
张老师：原 pptx 就行。pdf 不太需要。
刘老师：能不能加一个权限？我作为普通老师不希望别人下载我的课件。
PM：可以，加一个"是否允许批量打包"的开关，默认关。
张老师：行。还有，如果中间失败了能不能告诉我哪些没打包成功？
PM：OK，加错误列表。
```

摘要（PRD 输入素材）：

```
[业务背景]
教研组长需要每月汇总全班课件，目前手动下载 + 打包耗时 1 小时。

[用户角色]
- 教研组长（主要使用者）
- 教师（受影响者：可控自己的课件是否被批量打包）

[核心动作]
1. 选择月份 + 班级（多选）
2. 一键生成压缩包
3. 通过邮件接收

[价值]
节省 1 小时 / 月的手动操作时间

[输入条件]
- 月份范围
- 班级列表（多选）
- 包含的课件范围（默认本月所有，可手动剔除）

[输出预期]
- ZIP 文件（含 PPTX 原格式）
- 邮件通知（含下载链接）

[验收标准]
- AC1: 单月 100 个课件打包 ≤ 5 分钟
- AC2: 部分失败不影响其他课件
- AC3: 报告失败课件列表
- AC4: 教师可关闭"被批量打包"开关，默认关
```

## 摘要原则

| 要 | 不要 |
|----|------|
| 保留具体数字（"1 小时" / "100 个课件"） | 模糊词（"很多" / "比较快"） |
| 保留约束（"默认关" / "原格式") | 笼统语言 |
| 区分多个角色的不同诉求 | 笼统说"用户" |
| 标注未明确的悬念（待澄清） | 假装已经明确 |

## 待澄清标注

```
[待澄清]
- 1 个 ZIP 上限多大？（200MB? 500MB?）
- 邮件链接有效期？
- 是否支持取消进行中的打包？
```

放进 PRD 文末的"Open Questions"段。

## 反例

```
❌ 直接复制粘贴会议记录到 PRD Overview
❌ 漏掉时间数字（"耗时很久" vs "1 小时"）
❌ 把多个角色合并成"用户"
```
